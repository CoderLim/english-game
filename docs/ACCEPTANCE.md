# MVP 验收与测试

## 功能验收

- [x] React + TypeScript + Vite 工程可构建（由 CI 验证）
- [x] 2024 新版 PEP 三年级上册目录展示，未实现单元明确锁定
- [x] Unit 1 前两关可玩：问候 / 自我介绍、机器人身体部位
- [x] 选择、点击目标、自评回忆三种练习形式
- [x] 每一次答题均记录 pointId、skill、独立正确与时间
- [x] 独立成功跨天升级，错误和求助不算独立掌握
- [x] 间隔复习队列 + 不同情境的教师编写复习变体
- [x] 浏览器本地进度保存，关闭/刷新可恢复关卡
- [x] 家长可查看学习状态，不冒充正式语言能力评价
- [x] 不要求注册，不上传儿童语音或个人信息

## 人工端到端冒烟测试

1. 首次进入游戏，看到 Unit 1 可玩与其余单元锁定。
2. 进入“森林里的新朋友”，听题并选择错误选项，看到正确答案提示，再继续。
3. 完成五题，其中最后一题口头说英文，再手动标记是否独立正确。
4. 返回地图，已通关标识生效，刷新仍在。
5. 进入“机器人需要帮助”，针对 ear/eye/mouth/hand/arm 点击对应 SVG 热区（移动端和桌面都能点）。
6. 中途刷新，恢复之前的关卡与进度。
7. 从家长页面查看记录；修改本机系统日期不建议用于真实验收，可通过纯函数测试模拟两天后到期。
8. 到期后进入复习入口，看到与原任务不同的复习题，完成后队列减少。
9. 浏览器禁止 localStorage 或语音不可用时，核心学习仍能继续，界面给出提示。
10. 使用 375px、768px 和 1440px 宽度检查布局。

## 自动化

`npm run test`：内容引用完整性 / 状态机 / 间隔日程；`npm run build`：TypeScript + Vite 产物。
